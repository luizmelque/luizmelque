Para mim, qualidade de software vai muito além de executar casos de teste.

Gosto de entender como os sistemas funcionam, questionar requisitos, identificar riscos antes do desenvolvimento e ajudar equipes a entregarem produtos mais confiáveis.

Minha trajetória na tecnologia começou depois de experiências em outras áreas, e foi justamente isso que me ensinou algo que hoje considero essencial para qualquer profissional de QA:

Atualmente estou desenvolvendo minha carreira em Quality Assurance com foco em testes manuais, análise de requisitos, testes de API, automação e engenharia de testes.

Meu objetivo é ser o tipo de QA que ajuda o time a evitar problemas antes mesmo que eles aconteçam.

# Meus princípios como QA

Alguns princípios orientam a forma como trabalho e estudo:

- Qualidade começa nos requisitos.
- Testar é reduzir riscos, não provar que um software é perfeito.
- Uma boa documentação economiza tempo para toda a equipe.
- Comunicação é uma das habilidades mais importantes de um QA.
- Todo bug possui uma causa. Encontrar essa causa gera mais valor do que apenas registrar o defeito.
- Automação deve simplificar processos, nunca aumentar a complexidade.
- Melhorar continuamente é parte do trabalho de um engenheiro.
